# outputs/

Results written by the notebooks (relative path `../../outputs/`), version-controlled
so the numbers in the root README can be checked without re-running anything:

- `metrics_*.csv`: per-technique performance (precision, recall, F1, accuracy,
  Cohen's κ; plus MAE/RMSE/R²/Spearman for BMWP regressors). The
  `*_nested_loocv.csv` files are the headline, out-of-sample estimates.
- `table_A…D_*.csv`: summary tables used in the manuscript.
- `numerical_bmwp_*.csv`, `*_loocv_predictions.csv`: per-station predictions.
- `sensitivity_*.csv`: AIC- vs. Spearman-based predictor selection.
- `*.png`: confusion matrices, fitted curves, trees, membership functions.
- `figures/article/`: publication figures 2–6 and 8.

Serialized models (`*.pkl`) and spreadsheets (`*.xlsx`) are **not** tracked (see
`.gitignore`); they are regenerated by re-running the notebooks.
